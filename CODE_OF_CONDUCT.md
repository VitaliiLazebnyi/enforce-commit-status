# Code of Conduct

This project follows the [Contributor Covenant, version 2.1][covenant].

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported through
[GitHub's private reporting tools][reporting] or by contacting the repository maintainer.

All complaints will be reviewed and investigated promptly and fairly.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
[reporting]: https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam
